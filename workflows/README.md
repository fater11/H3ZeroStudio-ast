# Примеры воркфлоу

Два файла — это один и тот же демо-проект (H3, 4 шага, 768×1344, один отрезок 124 кадра ≈ 5 с).

| файл | для чего |
|---|---|
| `h3lab_4step_demo_ui.json` | перетащить в ComfyUI (Workflows → Open) и нажать Run. Вся работа идёт внутри ноды `ZL_H3ZeroStudioLab`: параметры, отрезки, референсы, апскейл |
| `h3lab_4step_demo_api.json` | формат API — для скриптов, `comfy_run`, очереди через `/prompt`. Плюс `PreviewImage` и `SaveAudio`, чтобы результат было видно |

Внутри ноды лежит JSON проекта: `settings` (4 шага, cfg 1, euler/simple, shift 12/3, 768×1344, seed)
и один отрезок с полным промтом H3 (`subject_definitions` → `summary` → `detailed_description` →
`overall_soundscape` → `non_diegetic_music`).

## Что поправить под себя

1. **Модель.** В ноде откройте параметры и выберите пресет или впишите файл: базовый H3 + pi-адаптер
   на 4 шага (или turbo-LoRA). Текстовый энкодер и оба VAE берутся из настроек ноды, отдельные
   загрузчики не нужны — поэтому в примере только одна нода.
2. **Промт и звук.** Отрезок правится в редакторе ноды (кнопка «Редактор»): текст, референсы,
   персонажи-карточки.
3. **Длина.** `frames` — кратное кадровой сетке H3 (124 кадра ≈ 5 с при 25 fps). Второй и следующие
   отрезки ставятся в режим `extend` с перекрытием.

## Проверено

Классы нод существуют на живом сервере (`/object_info`), проект внутри файла проходит
`h3s_core.normalize_project` без потерь (4 шага, 768×1344, 124 кадра), индексы выходов
`images=0`, `audio=1` совпадают с `output` ноды.
