# Разбор чужих воркфлоу: ErosMax H3 Turbo 2-pass (simple v4 / advanced v5)

Два готовых графа ComfyUI (`H3_Turbo_2Pass_ErosMax_v1_simple_v4.json`,
`H3_Turbo_2Pass_ErosMax_v1_advanced_refmods_v5.json`). Ниже — что в них полезного для
H3ZeroStudio Lab, а что у нас уже есть.

## Уже есть у нас (совпадает по смыслу)

| в воркфлоу | у нас в Lab |
|---|---|
| два прохода: черновик в низком разрешении → латентный апскейл → доработка | режимы «2 этапа» и «Low Res → High Res» (`final_mode: refine` / `luna`) |
| LBH 2D / native 3D латентный апскейлер | `h3s_upscale`: native (ComfyUI) / Pixaroma / LBH 3D / LBH 2D, выбор в настройках |
| `MiniMaxH3SigmaShift` 12 / 3 | `shift_video` / `shift_audio` ✓ |
| `BasicScheduler` 2-го прохода (linear_quadratic, denoise 0.3) | «Независимые 2 прохода» → переключатель BasicScheduler ✓ |
| `RandomNoise` с одним сидом на оба прохода | у нас одно поле шума на весь ролик (сильнее: поле общее и по абсолютным кадрам) |
| звук всегда из первого прохода | второй проход сохраняет звук черновика ✓ |
| длительность → кадры по сетке 17k+5 | `core.snap_frames` ✓ |
| «Wait for video/RTX — decode audio last» | свой VRAM-арбитр (`h3s_vram`) ✓ |
| превью через tiny VAE (taeh3) | `preview_tiny_vae` ✓ |
| RTX super-resolution 1.3× (ULTRA, 10-bit) | своего RTX-апскейла нет, есть свой «Апскейл отрезка» (обучаемый 2D/3D) |
| «Continue: яркость нового отрезка подгоняется под конец исходника, правка меряется на каждом стыке» | `level_lock` — ровно то же, и по замерам он поднимает шов с ×5.09 до ×1.65 |
| стартовый кадр как гид в обоих проходах (`MiniMaxH3AddGuide`, frame_idx 0) | у нас сильнее: перенос латента + замок + `<Picture N>` |

## Стоит взять

1. **3D-апскейлер на стыках с исходным видеом.** В воркфлоу прямо написано: LBH 2D
   «чуть сдвигает геометрию», поэтому в режиме Continue там автоматически выбирается
   встроенная 3D-модель ComfyUI (`MiniMaxH3LatentUpscaleWithModel`). У нас выбор модели
   общий для всех клипов. **Сделано:** подсказка под выбором модели в «HiRes · Проход 2» и
   строка в подробном логе, когда реально выбрана 2D-модель.

2. **Зерно на экспорте + CRF/пресет кодировщика.** В воркфлоу: CRF 18, пресет `slow`,
   зерно 0.005 (Lokken VideoTools), 24 fps. У нас финальный экспорт — CRF 16 (лучше) и
   пресет по умолчанию `superfast` для превью, `medium` для экспорта. **Идея:** дать
   «плёночное зерно» и пресет кодировщика как настройки экспорта — зерно маскирует
   блочность H3 на 24 fps и стоит почти ноль.

3. **`BlockSparseAttention` (VSA) как ускоритель.** Ядро ComfyUI 0.38+ умеет разреженное
   внимание (`keep_percent 10`, `dense_blocks "0,1"`). У нас в «Ускорении» только
   kitchen/sage/flash/pytorch. На 16 ГБ это может дать заметный выигрыш в скорости —
   стоит добавить пункт «разреженное внимание (VSA)» в секцию ускорения.

4. **LCM даёт лучший звук** (из их примечаний: «LCM tends to give the best audio at the
   expense of motion and image fidelity»). LCM у нас есть в списке сэмплеров — стоит
   перенести это замечание в подсказку к сэмплеру.

5. **RefMods** (`ComfyUI-MiniMaxH3Mod`): персонаж как один сохранённый `.safetensors`
   (визуал + звук), слоты с силой и копиями, применяется к кондишингу обоих проходов.
   У нас персонаж — это карточка с картинками и голосом. RefMods — естественное
   расширение карточки (одна кнопка «экспорт персонажа в RefMod» + слот в карточке).

## Не берём

- **Экспорт «оставить все кадры исходника + приклеить новый клип»** — у нас своя схема
  (перекрытие вырезается, склейка идёт по латинту); она проверена замерами и работает.
- **Пустые «Additional references» на 8 картинок / 2 видео / 3 аудио** — у нас референсы
  уже есть, но лимит на клип у нас меньше (3 аудио); расширять надо по запросу.
- **RTX FrameGen (48–120 fps)** — это интерполяция чужой ноды; в Lab приоритетнее стабильный
  24 fps (у нас так и есть).

## Итог

Архитектура генерации у нас уже не хуже: мы добавили то, чего у них нет (общее поле шума на
абсолютных кадрах, замок перекрытия в латинте, Studio-цвет на стыке, кэш AV-латентов).
Из их воркфлоу берём по мелочи: подсказку про 3D-апскейлер на стыках (сделано), зерно/CRF
в экспорт, VSA в ускорение, RefMods в карточку персонажа, заметку про LCM.
