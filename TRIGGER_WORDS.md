# LoRA Trigger Words

Вкладка «Модели и LoRA» → ⓘ у нужной LoRA → Auto Trigger Words и текст через запятую.

По умолчанию выключено. Данные хранятся в записи LoRA пресета (`auto_trigger`, `trigger_words`) и сохраняются вместе с пресетом. Включённые слова добавляются только к визуальному промпту соответствующей сцены, без изменения исходного текста. При изменении слов меняется ключ кеша сцены.

Автоматическое чтение из safetensors и общая база слов в этой версии не реализованы.
