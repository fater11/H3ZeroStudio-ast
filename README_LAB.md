# H3ZeroStudio Lab — локальный эксперимент

Копия H3ZeroStudio 1.0.6 (коммит cb6c49a) с новым слоем UI-эффектов. **Не для гита и не для Comfy Registry.**

Работает рядом с основной нодой без конфликтов:

| что | основная нода | Lab |
|---|---|---|
| id ноды | `ZL_H3ZeroStudio` | `ZL_H3ZeroStudioLab` (в меню: MiniMax H3 → H3ZeroStudio Lab) |
| маршруты сервера | `/h3zero/*` | `/h3lab/*` |
| событие прогресса | `h3zero.progress` | `h3lab.progress` |
| данные | `output/h3zerostudio` | `output/h3labstudio` (при первом запуске копируются только `_settings.json` и пресеты моделей) |
| CSS-префикс / localStorage | `h3z-` / `h3zs.*` | `h3l-` / `h3ls.*` |
| расширение фронтенда | `zl.h3zerostudio` | `zl.h3labstudio_lab` |

Эффекты: `web/js/lab/` (fx.js — вход, fx_gl.js — WebGL-фон и стекло, fx_interact.js — слой взаимодействий,
fx_sparks.js — оверлей, fx_ptext.js — логотип из частиц, fx_css.js — стили и тема «Lab»).
Настройки → «Эффекты Lab»: MAX / Высокое / Низкое / Выкл, авто-снижение, заморозка фона во время генерации.
Удалить эксперимент: удалить эту папку (и при желании `output/h3labstudio`).

## Экспериментальные настройки H3ZeroStudio Lab

- **Karras для High Res:** «Настройки → Генерация → Low Res → High Res → Эксперимент: Karras ρ=7». По умолчанию выключен, влияет только на интервалы шагов High Res; количество шагов, начальная/конечная σ и обычный кэш не меняются. Для Karras кэш отдельный. Это вариант для сравнительных тестов, а не обещание ускорения или качества.
- **Текстовые энкодеры в Ассистенте:** «Ассистент → Настройки → Подключение → Источник ответов → Текстовый энкодер ComfyUI (Gemma) → Обновить». Выберите установленный энкодер (например, `gemma4_12b_h3_pe_int8.safetensors`). Старый OpenAI-совместимый API остаётся отдельным вариантом.
- Для Gemma применяется `CLIPLoader → TextGenerateV2` внутри ComfyUI; основной Qwen3VL, VAE и модели видео не подменяются. «Улучшить промпт» в редакторе использует выбранный источник ответов.
- Чтобы защищать VRAM пользователей с 12–24 GB, видеогенерация и ответ энкодера не запускаются одновременно: если очередь ComfyUI занята, ассистент попросит дождаться её завершения. В один запрос передаются максимум четыре изображения, уменьшенные до 768 px, а после ответа энкодер освобождает память.
- **Полные 8 шагов и экономия памяти:** при `memsave = Авто` на GPU с 22 ГиБ VRAM и выше, без ControlNet и сверхдлинной последовательности, сохраняется обычный MLP без разбиения. На менее объёмной видеопамяти и при ControlNet автоматическое разбиение доступно; ручные `Вкл`/`Выкл` имеют приоритет. Изолированный тест RTX 3090 (8 шагов, 260 кадров, 768×1344) показал, что разбиение на 2 части замедлило сегмент на ~45 секунд и изменило латенты. Поэтому оно не считается ускорением или гарантией идентичного результата.
- **Превью редактора:** уменьшение кадров перед MP4 выполняется пакетно с антиалиасингом, до 16 кадров за раз; резервный путь Pillow сохраняется. Это затрагивает только уменьшенные превью, не оригинальный мастер. В синтетическом тесте на данном ПК подготовка/кодирование 80 кадров сократилась с 4,6 до 2,5 с; выигрыш полного проекта может отличаться.
- После изменения Python-маршрутов или логики генерации требуется **перезапуск ComfyUI**. Не перезапускайте во время активного рендера.
